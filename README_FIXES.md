# RADUN — прошивка полётного контроллера для AT32F435G

## Состояние проекта

**Готовность к полёту: 2/10 → этап P0 завершён, собирается и линкуется.**

Проект прошёл технический аудит (разбор всех 30 файлов, сверка карты регистров с официальной библиотекой AT32F435 BSP v2.0.9, пробная сборка флагами Makefile). Критические блокеры P0 устранены: образ собирается, таблица векторов на месте, FPU включён, тактирование корректно. На hardware плата пока не飛ёт — требуется этап P1 (периферия) и P2 (управление).

## Целевая аппаратная платформа

- Плата: ACCIF435
- MCU: AT32F435G (Cortex-M4, до 288 МГц)
- Датчики: BMI270 IMU (SPI1), BMP280 барометр (I2C1)
- Протокол моторов: DSHOT600 (реализован транспорт, требует верификации DMA на железе)
- Приёмник: CRSF (ELRS / Crossfire) на USART6
- Интерфейс: USB CDC/VCP (заглушка) + CLI на USART6 (временно, до выноса на USB)

## Что исправлено (P0 — блокеры запуска)

| Блок | Было | Стало |
|------|------|-------|
| Сборка/линковка | Не собирается (4 ошибки компиляции + 1 линковка) | Собирается чисто, `--gc-sections` не вырезает векторы |
| Таблица векторов | `g_pfnVectors` выброшен линкером; по `0x08000000` был код функции | `.section .isr_vector` + `KEEP` в `.ld`, SP/PC валидны |
| FPU (CPACR) | Не включён → UsageFault на первом float | Включён в `SystemInit()` первой строкой |
| Тактирование PLL | `RCC->PLL` с `pllns=71`, без таймаута, без `pllfr` | HICK 48 МГц по умолчанию (`CLOCK_USE_PLL=0`), PLL 288 МГц опционально с таймаутом и fallback |
| Тактирование AHB/APB | Запись в `clkint`/`ahb1rst` (смещения 0x0C/0x10) | Корректные `ahb1en=0x30`, `apb1en=0x40`, `apb2en=0x44` |
| GPIO / pinmux | `BCLR`→`wpen`, `AFSEL[0]`→`muxh`, `AFSEL[1]`→`clr` | `gpio_clr` через `CLR`, `gpio_af` через `MUXL`/`MUXH` |
| USART baud | `PCLK/(16*baud)` (STM32) → 16× завышение | `PCLK/baud` (AT32) |
| TMR6/TMR7 clock | Не включалось вообще | Включается через `CRM_APB1EN` (биты 4, 5) |
| Дубли кода | `main.c`/`main_fixed.c`, `dshot_real.c`/`dshot_bidir.c`, `bmi270_real.c`/`bmi270_fixed.c` | Собирается только `main_fixed.c` + `dshot600.c` + один BMI270 |
| Коммитные `.o` | Маскировали неработоспособность сборки | Удалены из индекса, добавлены в `.gitignore` |
| CI | Отсутствует | Требуется добавить `make` на push |

## Что ещё не готово (P1/P2)

- **DShot600 DMA**: транспорт реализован (`radun_fix/dshot600.c`), но номера DMA-каналов/запросов TMR1_CHx и номера AF для пинов моторов нужно сверить с платой ACCIF435 (TODO в коде)
- **BMI270**: SPI-обмен логически верен, но CS через `gpio_clr` теперь работает; требуется верификация WHO_AM_I == 0x24 и стабильные 3200 Гц
- **CRSF**: парсер и CRC8 верны, но реальный LQ из кадра 0x14 не читается; UART на USART6 теперь с корректным baud
- **ADC**: читается один канал в TIM7; нужен ADC+DMA cyclic для двух каналов (VBAT + ток)
- **Blackbox**: запись без стирания секторов → потеря после 4 КБ; нужен переход на следующий сектор
- **PID**: один вызов на такт, новые единицы, но требуется перенастройка под реальный дрон
- **AHRS**: `fast_inv_sqrt` безопасен, но нет инициализации кватерниона по акселерометру и защиты от ускорений
- **CLI/МSP**: печатают в USART6 (тот же порт, что CRSF) —нужен отдельный UART или USB VCP

## Сборка

### Требования
- `arm-none-eabi-gcc` (например, 12.2.1)
- `make`

### Компиляция
```bash
make clean
make
```

### Проверка размера и секций
```bash
make size
arm-none-eabi-objdump -h radun_accif435.elf   # должен быть .isr_vector
arm-none-eabi-nm -n radun_accif435.elf        # g_pfnVectors, Reset_Handler, SystemInit
```

### Конфигурация тактирования
В `Makefile` задан `-DCLOCK_USE_PLL=0` (HICK 48 МГц) — для первого включения платы.  
Для 288 МГц установите `-DCLOCK_USE_PLL=1` и сверьте `PLL_FR_288` / `FLASH_WS` в `radun_fix/hal_at32.c` с даташитом вашей платы.

## Дорожная карта до первого полёта

**Этап 0 — «плата живая» (завершён)**  
`make` зелёный, образ содержит `.isr_vector`, LED мигает 500 мс, `hal_ms()` корректен.

**Этап 1 — «периферия отвечает»** (в прогрессе)
- SPI + BMI270: WHO_AM_I == 0x24, стабильные 3200 Гц
- CRSF: парсинг кадров, потеря кадра → failsafe
- ADC+DMA: bat.v сходится с мультиметром ±0.1 В
- DShot600 на осциллографе: 16 импульсов, T0H=625 нс, T1H=1250 нс

**Этап 2 — «стенд»** — blackbox, контур 8 кГц, настройка PID, проверка защита.

**Этап 3 — «полёт»** — висение, круги, 10 успешных полётов перед Angle/Horizon.

## Безопасность

⚠️ Не запускать на летательном аппарате без стендовой проверки. Перед полётами обязательно проверить порядок и направление вращения моторов, arming/disarming, failsafe, low-voltage cutoff.

## Структура исправлений

- `radun_fix/radun_hw.h` — корректная карта регистров AT32F435
- `radun_fix/hal_at32.c` — FPU, PLL, GPIO, USART, SPI, таймеры
- `radun_fix/dshot600.c` — транспорт DShot600
- `startup.s` — `.isr_vector` секция
- `AT32F435G.ld` — `KEEP(.isr_vector)`
- `radun.h` — тянет `radun_hw.h`, исправлены типы
- `main_fixed.c` — единственная точка входа, FSM арма, один PID на такт
- `pid.c`, `modes.c`, `crsf.c`, `failsafe.c`, `usb_cdc.c`, `flash_log.c` — целевые исправления
